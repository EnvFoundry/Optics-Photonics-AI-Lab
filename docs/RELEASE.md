# Optics & Photonics 0.11.3

The product now starts from 27 research tasks in four areas and shared optical foundations. The tasks use 34 open-source components; a separate software view exposes all 77 open-source entries. Commercial applications remain in the optional connection reference. Module selections resolve to existing solver recipes, and shared software is kept when another selected module still uses it.

Each task links to its domain methods and editable programs. Knowledge, task prompts, workflows and external connections have separate resource declarations. The default instructions are shorter; detailed material remains available on demand. Installation links point to EnvFoundry.

Research OS places new solver installations in System/software/optics-photonics. Connection settings and research records keep their existing location. Earlier installations are reused, and package resources provide Skills and knowledge without creating extra copies.

Linux plans now identify Windows-only connector routes before installation. Native preparation returns the solver executable rather than its Python driver, and a missing executable no longer appears ready because the driver exists. Existing direct software IDs, bindings and calculation records remain usable.

Published native executors cover Linux and Windows on x86_64 and ARM64. macOS native packaging is deferred; its checks remain available through the manual workflow.

## 中文

产品以四个研究领域和共用光学基础下的 27 个研究任务为入口。任务使用 34 项开源组件，独立的软件视图保留全部 77 项开源软件；商业软件只在可选接入资料中出现。模块选择复用已有求解器配方，同一软件供多个已选模块使用时保留共享安装。

每个任务关联领域方法与可编辑程序；知识、任务提示词、工作流和外部连接分别提供资源入口。默认指导文字精简，详细资料按需读取。安装链接统一指向 EnvFoundry。

Research OS 将新求解器安装在 System/software/optics-photonics，连接配置与研究记录保留原有位置。已有安装继续复用，Skills 和知识通过包内资源入口读取，避免重复复制。

Linux 准备计划会提前说明仅支持 Windows 的接口。原生软件的准备结果返回求解器可执行文件，而非驱动 Python；求解器缺失时不会因 Python 仍存在而显示已准备。原有软件 ID、连接与计算记录继续可用。

本次原生执行器覆盖 Linux、Windows 的 x86_64 和 ARM64。macOS 原生打包后置，可通过手动工作流单独运行相关检查。
